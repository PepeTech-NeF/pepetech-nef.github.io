# PepeTech

**PepeTech** — портфолио техники, построенной **nef1c** в Minecraft на сервере **PepeLand 11**. Военная техника и не только.

**Сайт:** https://pepetech-nef.github.io/

## Стек

- **Astro** — статический сайт;
- **JavaScript и CSS** — интерфейс, фильтры и просмотр фотографий;
- **GitHub Pages + GitHub Actions** — хостинг и сборка;
- **Pages CMS** — добавление техники и изображений.
